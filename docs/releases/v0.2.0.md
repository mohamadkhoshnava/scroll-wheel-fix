## Scroll Wheel Fix: cross-platform preview

The project has been renamed from **M220 Scroll Fix** to **Scroll Wheel Fix**. The filter is no longer presented as model-specific: it targets brief wrong-direction wheel bursts from supported mouse input formats, regardless of brand.

### Downloads

- **macOS 13+:** universal app for Apple Silicon and Intel. Accessibility permission required; ad hoc signed, not notarized.
- **Windows 10/11 x64:** portable native tray executable. Unsigned; run in your normal user session.
- **Linux x64:** foreground evdev/uinput CLI, built on Ubuntu 24.04. Requires libevdev and compatible system runtime, access to the selected mouse and uinput, usually sudo. Read `linux.md` before running.
- `SHA256SUMS.txt` lists archive checksums.

### Added

- Win32 tray controls, bounded reverse-wheel buffering, replay recursion protection, and pause-on-replay-failure behavior.
- Linux explicit mouse selection, paired legacy/high-resolution wheel filtering, movement/button forwarding, and device release on exit/error.
- Native C++ regression checks and Linux wheel-frame tests.
- Automated builds for all three platforms, public tagged preview releases, platform setup guides, compatibility reporting, and Persian documentation.

### Verification and limitations

Automated builds and synthetic tests run on all three OS runners. Earlier macOS/M220 use indicated improvement. **Windows and Linux live hardware behavior has not yet been manually verified.** CI does not grab a physical mouse or install a live hook.

This is a noisy-input workaround, not a hardware repair or universal mouse certification. Intentional quick reverse ticks may be suppressed or delayed; noise after idle or sustained faulty bursts can still pass. See the included platform guides and compatibility table.

Quit the original M220 utility before opening the renamed macOS app. It uses a new bundle identity and needs its own Accessibility permission. No backend installs automatic startup or a background service.
