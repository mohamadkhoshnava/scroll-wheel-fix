# M220 Scroll Fix

ابزار کوچک برای مک که پرش‌های کوتاه چرخ ماوس به جهت مخالف را فیلتر می‌کند. این برنامه برای قابل‌استفاده‌تر شدن یک Logitech M220 با اسکرول معیوب ساخته شده است.

[English documentation](README.md) · [مجوز MIT](LICENSE)

این ابزار یک راهکار نرم‌افزاری است و خرابی قطعه را تعمیر نمی‌کند. تغییر عمدی جهت ممکن است کمی مکث داشته باشد و یک تک‌حرکت سریع در جهت مخالف هم ممکن است حذف شود.

## امکانات

- عبور اسکرول در همان جهت، بدون تأخیر عمدی.
- حذف پرش‌های کوتاه به جهت مخالف و حفظ تغییر جهت‌های ادامه‌دار.
- دو حالت متعادل با بازهٔ تأیید ۸۰ میلی‌ثانیه و قوی با بازهٔ ۱۴۰ میلی‌ثانیه.
- عبور بدون تغییر اسکرول پیوسته، اسکرول افقی و اسکرول همراه کلیدهای Shift، Control، Option یا Command.
- کنترل توقف، فعال‌سازی و خروج از منوی بالای صفحه.
- بدون وابستگی به کتابخانه‌های شخص ثالث، شبکه یا حساب کاربری.

## پیش‌نیاز و ساخت

مک با macOS 13 یا جدیدتر و Xcode یا Command Line Tools که کامپایلر Swift را در اختیار `xcrun` قرار دهد لازم است. رفتار برنامه فعلاً فقط روی یک مک با ماوس M220 به‌صورت دستی بررسی شده است؛ حداقل نسخهٔ هدف ساخت، تضمین تست روی همهٔ نسخه‌ها نیست.

```bash
git clone https://github.com/mohamadkhoshnava/m220-scroll-fix.git
cd m220-scroll-fix
./scripts/test.sh
./scripts/build.sh
```

برنامه در مسیر `dist/M220 Scroll Fix.app` ساخته می‌شود. آن را با Finder به پوشهٔ Applications منتقل و اجرا کن. اگر نسخه‌ای از قبل نصب است، پیش از جایگزینی از آن خارج شو. اسکریپت ساخت فقط داخل همین مخزن فایل می‌سازد و برنامهٔ نصب‌شده را جایگزین نمی‌کند.

خروجی متناسب با معماری همان مک، Apple Silicon یا Intel، ساخته می‌شود؛ فایل universal نیست. امضا از نوع محلی ad hoc است و برنامه امضای Developer ID یا تأیید notarization اپل ندارد. روش اصلی نصب، ساخت از سورس است.

## فعال‌سازی

۱. برنامه را اجرا کن و دکمهٔ «باز کردن تنظیمات Accessibility» را بزن.

۲. در **System Settings → Privacy & Security → Accessibility**، اگر نام برنامه نیست با دکمهٔ **+** نسخهٔ نصب‌شده را اضافه کن و کلید آن را روشن کن. ممکن است مک احراز هویت بخواهد.

۳. چند ثانیه صبر کن. علامت **M220 ✓** یعنی فیلتر فعال است. **M220 ○** یعنی فیلتر متوقف است یا مجوز لازم را ندارد.

اگر مجوز روشن است ولی فیلتر متصل نمی‌شود، برنامه را ببند و دوباره اجرا کن. جابه‌جایی یا ساخت دوبارهٔ برنامه ممکن است به افزودن مجدد آن در Accessibility نیاز داشته باشد.

برنامه به‌صورت خودکار با ورود به مک اجرا نمی‌شود. برای اجرای خودکار می‌توانی خودت آن را از تنظیمات Login Items مک اضافه کنی.

## منوی برنامه

| گزینه | کاربرد |
| --- | --- |
| Pause filter / Enable filter | توقف یا فعال‌سازی فیلتر |
| Balanced — 80 ms | حالت پیش‌فرض متعادل |
| Strong — 140 ms | تأیید طولانی‌تر جهت؛ احتمال مکث بیشتر هنگام تغییر جهت |
| Wheel / suppressed | شمارندهٔ ورودی چرخ و فرمان‌های بافرشدهٔ حذف‌شده |
| Continuous input passed through | شمارندهٔ رخدادهای پیوسته که بدون تغییر عبور کرده‌اند |
| Setup and help | باز کردن راهنما |
| Quit M220 Scroll Fix | خروج و توقف کامل فیلتر |

حالت انتخاب‌شده، وضعیت توقف و شمارنده‌ها با اجرای دوباره بازنشانی می‌شوند. شمارندهٔ فرمان‌های حذف‌شده ممکن است تا رسیدن رخداد بعدی یا بازنشانی، با تأخیر به‌روز شود.

## روش کار و محدودیت‌ها

فیلتر آخرین جهت پذیرفته‌شده را نگه می‌دارد. رخداد مخالف را موقتاً بافر می‌کند. اگر جهت قبلی برگردد، رخدادهای مخالف حذف می‌شوند. اگر دست‌کم دو رخداد مخالف در فاصله‌ای برابر یا بیشتر از بازهٔ تأیید ثبت شود، جهت جدید پذیرفته و رخدادهای بافرشده بازپخش می‌شوند. پس از بیش از ۶۰۰ میلی‌ثانیه بدون رخداد پذیرفته‌شده، جهت بازنشانی می‌شود و رخداد بعدی مستقیم عبور می‌کند.

بازهٔ ۸۰ یا ۱۴۰ میلی‌ثانیه یک آستانه است؛ تایمری برای آزادکردن خودکار فرمان وجود ندارد. تغییر عمدی جهت تا رسیدن فرمان بعدی منتظر می‌ماند و یک تک‌حرکت سریعِ مخالف ممکن است حذف شود. پرش پس از مکث یا خطای ادامه‌دار هم ممکن است عبور کند.

رخدادهای Quartz مدل ماوس را مشخص نمی‌کنند؛ بنابراین فیلتر روی **همهٔ چرخ‌های غیرپیوستهٔ عمودی** اثر می‌گذارد، نه فقط M220. اسکرول پیوسته که معمولاً از ترک‌پد یا ابزارهای smooth scroll می‌آید دست‌کاری نمی‌شود. پیوسته‌بودن فرمت رخداد را توصیف می‌کند و تضمین تشخیص نوع دستگاه نیست.

در استفادهٔ اولیه با یک M220 بهبود گزارش شده است؛ نرخ موفقیت عددی در تست زنده ثبت نشده و حذف همهٔ پرش‌ها یا سازگاری با همهٔ دستگاه‌ها تضمین نمی‌شود. تست‌های خودکار با ورودی مصنوعی انجام می‌شوند و جای تست سخت‌افزار واقعی را نمی‌گیرند.

## حریم خصوصی

کد برنامه فقط رخداد اسکرول را از سیستم درخواست می‌کند. متن کیبورد، کلیک، حرکت نشانگر و محتوای صفحه خوانده نمی‌شوند. ارتباط شبکه‌ای، تله‌متری، حساب کاربری یا ذخیرهٔ تاریخچهٔ اسکرول وجود ندارد؛ شمارنده‌ها در حافظه هستند. مجوز Accessibility در سطح مک گسترده است و باید خودت آن را در تنظیمات بدهی.

داده‌های تست شخصی و مشخصات محلی دستگاه در این مخزن قرار ندارند. سورس و توضیح ساخت در [راهنمای انگلیسی](README.md) آمده است. GitHub Actions تست و ساخت را روی مک اجرا و خروجی ZIP را به‌عنوان artifact همان اجرا نگه می‌دارد؛ این خروجی انتشار notarized نیست.

## حذف

از منوی M220 خارج شو، مجوز Accessibility را بردار و برنامه را به Trash منتقل کن. این پروژه سرویس پس‌زمینه یا Login Item نصب نمی‌کند.
