# Scroll Wheel Fix — رفع پرش اسکرول ماوس

ابزار متن‌باز برای کاهش **پرش اسکرول به جهت مخالف، بالا رفتن ناگهانی هنگام اسکرول به پایین و لرزش چرخ ماوس** در مک، ویندوز و لینوکس.

[دانلود نسخهٔ پیش‌نمایش ۰٫۲٫۰](https://github.com/mohamadkhoshnava/scroll-wheel-fix/releases/tag/v0.2.0) · [English](README.md) · [مجوز MIT](LICENSE)

نام قبلی پروژه **M220 Scroll Fix** بود. برنامه ابتدا برای یک Logitech M220 ساخته شد؛ اکنون محدودیت برند و مدل ندارد. مناسب‌بودن آن به نوع رخداد چرخ و سیستم‌عامل بستگی دارد. این به معنی تست‌شدن روی همهٔ ماوس‌ها نیست.

فیلتر خرابی قطعه را تعمیر نمی‌کند؛ فرمان‌های کوتاهِ مخالف را مهار می‌کند. تغییر عمدی جهت ممکن است تا رسیدن فرمان بعدی مکث داشته باشد و یک تک‌حرکت سریع در جهت مخالف هم ممکن است حذف شود.

## دانلود و وضعیت پشتیبانی

| سیستم | فایل | رابط و دسترسی | وضعیت بررسی |
| --- | --- | --- | --- |
| macOS 13+ | `Scroll-Wheel-Fix-macOS-universal.zip` | برنامهٔ منوی بالا؛ Intel و Apple Silicon؛ مجوز Accessibility | تست و بیلد خودکار؛ نسخهٔ اولیه روی یک مک با M220 استفاده شده |
| Windows 10/11 x64 | `Scroll-Wheel-Fix-Windows-x64.zip` | برنامهٔ قابل حمل کنار ساعت؛ نشست عادی کاربر | بیلد و تست خودکار؛ تست واقعی ماوس هنوز لازم است |
| Linux x64 | `Scroll-Wheel-Fix-Linux-x64.tar.gz` | خط فرمان؛ انتخاب یک ماوس با evdev/uinput؛ معمولاً sudo | بیلد، تست منطق و فریم اسکرول؛ تست سخت‌افزار و compositor هنوز لازم است |

نسخهٔ مشترک سه سیستم **پیش‌نمایش** است. فایل‌های برنامه و `SHA256SUMS.txt` در صفحهٔ دانلود هستند. بیلد لینوکس روی Ubuntu 24.04 انجام می‌شود و به `libevdev.so.2` و runtime سازگار نیاز دارد؛ برای توزیع یا معماری دیگر از سورس بساز.

بیلد ویندوز امضای ناشر ندارد؛ امضای مک محلی ad hoc است و notarization اپل ندارد. هیچ حساب کاربری یا ارتباط اینترنتی برای اجرای فیلتر لازم نیست.

## راه‌اندازی مک

۱. ZIP را باز کن، **Scroll Wheel Fix.app** را به Applications منتقل و اجرا کن.

۲. در **System Settings → Privacy & Security → Accessibility** مجوز برنامه را روشن کن؛ در صورت نبودن نام برنامه، آن را با **+** اضافه کن.

۳. علامت **SWF ✓** یعنی فیلتر فعال است. از همان منو توقف، حالت متعادل یا قوی و خروج را انتخاب کن.

پیش از اجرای نسخهٔ جدید، نسخهٔ قدیمی M220 را ببند. برنامهٔ تغییرنام‌یافته شناسهٔ متفاوتی دارد و مجوز خودش را می‌خواهد. [جزئیات مک](docs/macos.md)

## راه‌اندازی ویندوز

ZIP را استخراج و **ScrollWheelFix.exe** را در نشست عادی کاربر اجرا کن. روی آیکن کنار ساعت، یا بخش آیکن‌های مخفی، راست‌کلیک کن. گزینه‌های توقف فیلتر، متعادل، قوی و خروج در آن قرار دارند. نصب‌کننده یا درایور لازم نیست.

برنامه‌های دارای دسترسی Administrator و بازی‌های raw input ممکن است رفتار متفاوتی داشته باشند. [جزئیات ویندوز](docs/windows.md)

## راه‌اندازی لینوکس

```bash
sudo apt install libevdev2
./scroll-wheel-fix --help
sudo ./scroll-wheel-fix --list
# eventN را با دستگاه واقعی ماوس جایگزین کن:
sudo ./scroll-wheel-fix --device /dev/input/eventN --mode balanced
```

این نسخه فقط **ماوس انتخاب‌شده** را موقتاً در اختیار می‌گیرد، یک ماوس مجازی می‌سازد و حرکت و دکمه‌های آن را عبور می‌دهد. فیلتر روی فریم‌های چرخ اعمال می‌شود. **Ctrl+C** آن را متوقف و ماوس را آزاد می‌کند. مسیر پیاده‌سازی به X11 وابسته نیست و برای Wayland هم طراحی شده، ولی تست واقعی compositor هنوز انجام نشده است.

قبل از اجرا، [دسترسی uinput و راهنمای توقف/بازیابی لینوکس](docs/linux.md) را بخوان. برنامه نودهای دارای کلیدهای کیبورد و دستگاه‌های absolute را رد می‌کند. هیچ قانون دسترسی دائمی یا سرویس root نصب نمی‌شود.

## حالت‌ها و محدودیت‌ها

حالت **Balanced** بازهٔ تأیید ۸۰ میلی‌ثانیه و **Strong** بازهٔ ۱۴۰ میلی‌ثانیه دارد. فرمان‌های همان جهت بدون تأخیر عمدی عبور می‌کنند. فرمان مخالف موقتاً نگه داشته می‌شود؛ بازگشت جهت قبلی آن را حذف می‌کند و ادامهٔ جهت مخالف در دست‌کم دو فرمان، تغییر جهت را تأیید و فرمان‌های ذخیره‌شده را بازپخش می‌کند. پس از بیش از ۶۰۰ میلی‌ثانیه بدون فرمان پذیرفته‌شده، جهت بازنشانی می‌شود.

این بازه یک آستانه است؛ تایمر آزادسازی خودکار وجود ندارد. خطای بعد از مکث یا خطای ادامه‌دار ممکن است عبور کند. برای مقایسه، فیلتر را موقتاً متوقف کن.

- مک روی همهٔ چرخ‌های عمودی غیرپیوسته اثر دارد؛ ورودی پیوسته، افقی و همراه کلیدهای کمکی عبور می‌کنند.
- ویندوز روی چرخ‌های عمودی معمولی در همان نشست اثر دارد؛ ورودی تزریق‌شده، fractional و همراه کلیدهای کمکی عبور می‌کنند.
- لینوکس فقط ماوس انتخاب‌شده را فیلتر می‌کند و دو نمایش معمولی/high-resolution چرخ را با هم تصمیم‌گیری می‌کند. کیبورد خوانده نمی‌شود، بنابراین اسکرول همراه کلیدهای کمکی هم فیلتر می‌شود.

سازگاری با همهٔ ترک‌پدها، درایورهای گیمینگ یا ابزارهای smooth scroll تضمین نشده است. [جدول سازگاری و محدودیت‌ها](docs/compatibility.md)

## بیلد و انتشار خودکار

[GitHub Actions](https://github.com/mohamadkhoshnava/scroll-wheel-fix/actions/workflows/ci.yml) با پوش روی main، Pull Request یا اجرای دستی، هر سه نسخه را می‌سازد و تست می‌کند. خروجی هر اجرا به‌صورت artifact قابل دریافت است و پس از ۱۴ روز منقضی می‌شود.

پوش تگ `v*` پس از موفقیت همهٔ پلتفرم‌ها، یک Release پیش‌نمایش شامل سه آرشیو و checksum می‌سازد. فایل‌های Release مسیر دانلود عمومی هستند. تست‌های CI به ماوس واقعی دسترسی ندارند و موفقیت بیلد، جای تست سخت‌افزاری را نمی‌گیرد.

## ساخت از سورس

```bash
git clone https://github.com/mohamadkhoshnava/scroll-wheel-fix.git
cd scroll-wheel-fix
```

برای مک، `./scripts/test.sh` و سپس `ARCHS=universal ./scripts/build.sh` را اجرا کن. برای ویندوز و لینوکس، راهنمای اختصاصی در پوشهٔ [docs](docs) قرار دارد. ساخت به ابزارهای استاندارد Swift یا C++/CMake نیاز دارد.

## حریم خصوصی و حذف

ارتباط شبکه‌ای، تله‌متری، ذخیرهٔ تاریخچهٔ ورودی یا اجرای خودکار نصب نمی‌شود. شمارنده‌ها در حافظه هستند. مک فقط رخداد اسکرول می‌خواهد؛ ویندوز رخدادهای غیرچرخ را مستقیم عبور می‌دهد و hook کیبورد ندارد؛ لینوکس فقط رخدادهای ماوس انتخاب‌شده را می‌خواند و عبور می‌دهد.

برای توقف از منوی مک/ویندوز خارج شو یا در لینوکس Ctrl+C بزن. سپس برنامه و مجوزی را که داده‌ای حذف کن. تنظیمات اسکرول سیستم بازنویسی نمی‌شوند.

برای گزارش مشکل، سیستم‌عامل، مدل ماوس، نوع اتصال، حالت فیلتر و نتیجهٔ مقایسه با فیلتر خاموش را بنویس. رمز، توکن، شمارهٔ سریال یا اطلاعات شخصی لازم نیست. [گزارش مشکل](https://github.com/mohamadkhoshnava/scroll-wheel-fix/issues/new/choose)
